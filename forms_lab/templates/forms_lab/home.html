Validation and Creation of Forms in Django

Virtual Laboratory

Start Experiment

Aim

To understand the creation and validation of forms in Django using Django Forms.

Introduction

Forms are an important part of web applications because they allow users to enter and submit information.

Django provides a built-in forms framework to create form fields, validate submitted data, display errors and access cleaned data.

In this experiment, you will explore how Django forms are created and how validation works when a user submits a form.

Theory

Django provides a form handling framework that allows developers to create forms and validate user input.

Django Forms support different field types, such as text, email, integer, choice and date fields.

When a form is submitted, Django validates the entered data using the rules defined in the form. The is_valid() method checks whether the submitted data is valid.

If the data is invalid, Django generates validation errors. If it is valid, processed data becomes available through cleaned_data.

Important Django concepts

  • forms.py: Defines form fields and validation rules.
  • POST: Sends submitted form data to the server.
  • is_valid(): Checks the submitted data.
  • errors: Contains validation errors.
  • cleaned_data: Contains validated values.

Case Study

Student Registration System

A college registration portal needs to collect student information such as name, email, age, contact details and course preferences.

Without validation, users might submit invalid email addresses, incomplete details or values outside the permitted range.

Django Forms can validate these entries on the server and return meaningful error messages before the submitted data is processed.

Application: This experiment simulates student registration and demonstrates how Django handles valid and invalid input.

Procedure

  1. Create a Django project.
  2. Create a Django application.
  3. Define form fields in forms.py.
  4. Specify validation rules for the fields.
  5. Display the form using an HTML template.
  6. Submit the form using a POST request.
  7. Validate submitted data using is_valid().
  8. Display validation errors or cleaned data.
  9. Test the form using both valid and invalid inputs.

What you will learn

  • How Django form fields are displayed.
  • How invalid entries generate errors.
  • How valid entries are processed.
  • How cleaned data is displayed after validation.

Observations

  • Django displays validation errors when submitted data fails the defined rules.
  • The is_valid() method determines whether the submitted data passes validation.
  • Valid form values can be accessed through cleaned_data.
  • Server-side validation helps prevent invalid data from being processed.
